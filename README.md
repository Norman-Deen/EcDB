# 📚 EcDB – Educational Project

**EcDB** is a database-driven application developed as part of a course assignment at EC Utbildning.  
It demonstrates core principles of relational database design, entity relationships, and data manipulation using SQL and C#.

---

## 🔍 Project Overview

This project simulates a small-scale database system for managing entities such as students, courses, and teachers.  
It was built to practice:

- Relational database modeling
- Entity Framework Core (EF Core)
- CRUD operations in C#
- Data validation and constraints

---

## ⚙️ Technologies Used

- ✅ C#
- ✅ .NET Core / ASP.NET Core
- ✅ SQL Server / LocalDB
- ✅ Entity Framework Core (EF Core)
- ✅ Visual Studio 2022+

---

## 🛠️ Getting Started

1. **Clone the repository**  
   ```bash
   git clone https://github.com/Norman-Deen/EcDB.git
```

2. **Open the solution in Visual Studio**

   * Make sure SQL Server or LocalDB is running.
   * Run database migrations (if required).

3. **Build and Run**
   Press `F5` or use:

   ```bash
   dotnet build
   dotnet run --project EcUtbildningDb/EcDB.csproj
   ```
